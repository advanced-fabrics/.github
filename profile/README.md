# Advanced Fabrics

Advanced Fabrics (AdvFab) is an API-first, GitOps-friendly framework for observable and programmable cloud-native network fabrics.

AdvFab defines portable APIs for topology, routing, observation, policy and controlled experiments. Implementations are composed from replaceable providers; the reference runtime uses Kubernetes, Cilium and FRR without making those technologies part of the core contract.

- Website: https://advfab.org
- Documentation: https://docs.advfab.org
- Specifications and AFEPs: https://spec.advfab.org
- Security reports: security@advfab.org

Advanced Fabrics was initiated by RE8CH and is being developed as an independent open source project. It is not a CNCF project and does not claim CNCF endorsement.
