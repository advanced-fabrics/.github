# Contributing

Contributions are welcome through issues and pull requests. Significant compatibility, security-boundary or protocol changes require an Advanced Fabrics Enhancement Proposal (AFEP) in the `spec` repository before implementation.

All commits must include a Developer Certificate of Origin sign-off (`git commit -s`). Contributors must follow the project Code of Conduct, add tests for behavioral changes, and avoid committing credentials, private topology or generated secrets.

Public APIs follow semantic versioning. A pull request that changes a GA API must link its AFEP and include compatibility and conformance updates.
